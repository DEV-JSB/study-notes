## 티키타카 — 질문하고 배운 것

### Q. `SM_Paper`는 Static Mesh야? 새로 만들어야 해?

- `SM_` = Static Mesh 접두사 (커뮤니티 표준, Allar 스타일 가이드)
- 기존 `Rectangle_`은 크기·분할·앞면 방향을 몰라서 새로 만듦. 나중에 휘게 하려면 **분할된 평면**이 필요함
- Triangles **48** = 4 × 6칸 × 칸당 삼각형 2개, Vertices **35** = (4+1) × (6+1). **숫자로 분할을 검증**할 수 있음
- 메시 에디터의 체크무늬는 메시 격자가 아니라 `WorldGridMaterial`의 **텍스처 무늬**. 실제 격자는 `Lit → Wireframe`으로 봄

### Q. 따로 테스트 레벨 안 만들고 기존 레벨에서 해도 돼?

- 돼도 됨(취향 문제). 대신 구버전 종이를 꺼둘 것
- 아웃라이너의 **눈 아이콘은 에디터에서만 숨김.** PIE에서는 그대로 돌아감
- 모델링 모드 결과물은 **지금 열린 레벨 옆 `_GENERATED/사용자명/`**에 저장됨 → 그래서 예전 메시가 `ThirdPerson/Maps/_GENERATED/mvat1/`에 있었음

### Q. Redirector가 뭔데? 왜 체크해야 보여?

- 언리얼 에셋은 서로를 **경로**로 참조함. 에셋을 옮기면 옛 자리에 **"새 주소 쪽지"**가 남음 = 리다이렉터
- 엔진 내부 배관이라 기본으로 숨김. 탐색기로 보면 1~2KB짜리 `.uasset`으로 남아 있음
- Unity는 `.meta`의 **GUID**로 참조해서 옮겨도 쪽지가 필요 없음 → Unity 감각으로 폴더를 막 옮기면 쪽지가 쌓임
- 습관: **옮기거나 이름 바꾼 뒤 커밋 전에 Fix Up Redirectors 한 번**
- 보이게 하는 옵션은 Settings(톱니)가 아니라 Filters 쪽에 있음. 몰라도 정리는 됨

### Q. 클래스도 똑같아? 리네임하면 그래서 문제가 생기는 거야?

- **블루프린트 클래스**는 `.uasset`이라 에셋과 똑같이 리다이렉터가 생김
- **C++ 클래스**는 리다이렉터가 자동으로 안 생김 → 상속한 BP가 깨지고, 레벨 인스턴스가 사라지고, UPROPERTY 값이 초기화됨
- 해결: `Config/DefaultEngine.ini`의 `[CoreRedirects]`에 손으로 적음 (`+ClassRedirects`, `+PropertyRedirects`)
- Unity의 `[FormerlySerializedAs]`와 같은 개념을 클래스 단위까지 손으로 하는 것

### Q. 이미터(Emitter)가 뭐야? 이거 하나를 이미터라고 해?

- **시스템 = 그릇, 이미터 = 한 종류의 파티클을 만들고 굴리는 단위**
- 예: `NS_Explosion` 시스템 안에 Fire / Smoke / Sparks 이미터
- Unity 대응: ParticleSystem 컴포넌트 하나 = 이미터, 여러 개를 묶은 이펙트 프리팹 = 시스템
- 노드의 `Empty`는 이미터 이름이라 `PaperEmitter`로 변경. 에셋 이름(`NS_PaperField`)과는 다름

### Q. Life Cycle Mode가 바뀌면 뭐가 좋아?

- **System**: 시스템이 이미터 수명을 관리. 더 가볍고 대부분 이걸 씀
- **Self**: 이미터마다 수명이 달라야 할 때 (불은 0.5초, 연기는 5초)
- 이미터 하나면 차이 없음 → 기본값 System 유지, 루프는 **System State**에서 Once
- System 모드면 Emitter State에 Loop Behavior가 **아예 안 보임.** "루프 설정 어딨지?"면 Life Cycle Mode부터 볼 것

### Q. Spawn Burst / Shape Location은 어디서 추가해?

- 칸마다 ⊕ 색이 다름: 주황 = Emitter, 초록 = Particle, 빨강 = Render. **엉뚱한 칸에서 검색하면 목록에 안 나옴**
- **Emitter Update** = "지금 **몇 개** 만들까" → Spawn Burst
- **Particle Spawn** = "태어난 파티클에 **어떤 값**을 줄까" → Initialize Particle, Shape Location
- Box Size Z = 0 → 높이 없는 판 = 전부 바닥 높이에 놓임
- 스택은 **위에서 아래로 실행**, 뒤의 모듈이 앞의 값을 덮어쓸 수 있음

### Q. Mesh Scale Mode를 Uniform으로 하는 이유 같은 거 몰라도 돼?

- **안 됨.** 다만 모든 옵션이 아니라 **"기본값에서 내가 바꾼 값"은 이유를 설명할 수 있어야 함**
- Uniform 1은 사실 Unset과 결과가 같음. 의도를 눈에 보이게 적은 것뿐
- 도구: 항목에 마우스를 올리면 Epic 툴팁, **노란 되돌리기 화살표 = 기본값에서 바꾼 값 = 설명할 수 있어야 하는 목록**

### Q. 하나의 종이를 구현 안 하고 왜 여러 개를 만들어?

- Niagara 모듈은 전부 **파티클 한 개 기준**으로 작성 → 사실 한 장을 구현하는 것. 150은 개수 다이얼
- 개발 중엔 **Spawn Count 1**로 줄여서 보는 게 원인 파악이 쉬움

### Q. HLSL이 뭐야? 쉐이더 코드 아니야?

- 원래 GPU 셰이더 언어(Unity 셰이더의 `HLSLPROGRAM` 안 코드). 문법은 C#과 거의 같음
- Niagara는 그래프를 내부적으로 HLSL로 바꿔 실행 → 그래서 Niagara 안에서 코드로 쓸 때 HLSL 문법을 씀
- Custom HLSL 노드 = 그래프 중간에 끼우는 **C# 함수 하나**. 왼쪽 핀 = 매개변수, 오른쪽 핀 = 반환값

### Q. sin, cos를 모르는데 어디까지 이해해야 해?

- 이해에는 세 층: **사용법(필수)** / 직관(있으면 좋음) / 원리(몰라도 됨)
- 쿼터니언 공식은 **"Z축용 `Quaternion.Euler`"**로 외워서 블랙박스로 씀
- sin/cos 직관: 반지름 1인 원에서 θ만큼 돈 점의 좌표가 (cos θ, sin θ) = **각도 → 방향**
- 앞으로 필요한 수학: 벡터 덧셈·곱셈 → **내적(dot), 외적(cross)** → exp 감쇠. 내적·외적이 핵심

### Q. 오브젝트 스폰하고 회전시키면 되지 왜 HLSL까지 써?

- Niagara 파티클은 GameObject가 아니라 **표의 한 줄**. 메서드가 없고, **Map Set으로 칸에 값을 씀**
  - `Instantiate` ↔ Spawn Burst / `SetPositionAndRotation` ↔ Map Set / `Quaternion.Euler` ↔ Custom HLSL
- 1단계만 보면 HLSL이 필수는 아님. **3단계 펄럭임에서 쿼터니언 직접 계산이 필요해서 미리 연습**한 것
- 액터 150개 스폰도 유효한 방법이지만, 매 프레임 150장 펄럭임 계산은 Niagara가 적합 (Unity라면 ParticleSystem을 쓰는 것과 같은 이유)

## 직접 짠 코드

```hlsl
float h = radians(YawDeg) * 0.5f;          // 각도 → 반각(라디안)
OutQuat = float4(0, 0, sin(h), cos(h));    // Z축 회전 쿼터니언 (x, y, z, w)
OutPos = InPos + float3(0, 0, Lift);       // 살짝 띄우기
```

- `YawDeg` 0~360: 모든 방향이 나오게 → 줄 맞춘 군대 같지 않고 흩어진 느낌
- `Lift` 0.1~0.6cm: 두께 0인 종이끼리 **Z-파이팅(깜빡임)** 방지. 눈엔 안 띄고 GPU는 구분할 만큼. 장마다 달라야 종이끼리도 안 깜빡임

- **`(0, 0, sin, cos)`처럼 `float4` 없이 괄호만 씀** → HLSL에서는 콤마 연산자라 **마지막 값만 남음.** 에러 없이 값이 틀리는 가장 위험한 버그
- **`OutQuat` 핀을 float로 만듦** → 에디터가 `float -> Quat` 변환 노드를 자동으로 끼워서 값 하나를 4칸에 복사 = 망가진 회전. **변환 노드 안의 선이 한 점에서 퍼지면 의심.** (Position ↔ Vector처럼 1:1이면 안전)
- **90도 테스트 후 Random을 다시 연결 안 함** → 150장이 전부 같은 방향. 입력 칸에 숫자가 보이면 연결이 안 된 것
