## 최종 코드

### `PaperSpawnInit` (Particle Spawn)

```hlsl
float h = radians(YawDeg)  * 0.5f;
float t = radians(TiltDeg) * 0.5f;
float sy = sin(h);  float cy = cos(h);
float sx = sin(t);  float cx = cos(t);
OutQuat = float4(cy*sx, sy*sx, cx*sy, cx*cy);
OutPos = InPos + float3(0,0,Lift);
```

- X축으로 `TiltDeg`만큼 기울인 뒤 Z축으로 `YawDeg`만큼 돌린 쿼터니언. `TiltDeg` = 0이면 예전 코드와 똑같아짐
- Map Set에 `AngVel`(Vector) = (0,0,0) 추가

### `PaperAero` (Particle Update, `PaperSim` 위)

```hlsl
// 3-1: 법선
float3 up = float3(0, 0, 1);
float3 t  = 2.0f * cross(Q.xyz, up);
N = up + Q.w * t + cross(Q.xyz, t);

// 3-2: 판 공기저항
float3 vn = dot(Vel, N) * N;
float3 vt = Vel - vn;
float keepN = max(0.0f, 1.0f - NormalDrag * DeltaTime);
float keepT = max(0.0f, 1.0f - PlaneDrag  * DeltaTime);
OutVel = vn * keepN + vt * keepT;

// 3-3: 펄럭임 - 회전시키는 힘
float3 v = Vel * 0.01f;
float3 torque = dot(N, v) * cross(N, v) * FlipStrength;
float keepSpin = max(0.0f, 1.0f - SpinDrag * DeltaTime);
float moving = step(1.0f, length(Vel));
OutAngVel = (AngVel + torque * DeltaTime) * keepSpin * moving;

// 3-3: 펄럭임 - 회전값에 누적
float3 dq  = Q.w * OutAngVel + cross(OutAngVel, Q.xyz);
float  dqw = -dot(OutAngVel, Q.xyz);
OutQuat = normalize(Q + 0.5f * DeltaTime * float4(dq, dqw));
```

| 핀 | 이름 (자료형) |
|---|---|
| 입력 | `Q` (Quat), `Vel` (Vector), `AngVel` (Vector), `DeltaTime` (float), `NormalDrag` (float), `PlaneDrag` (float), `FlipStrength` (float), `SpinDrag` (float) |
| 출력 | `N` → PaperNormal, `OutVel` → Velocity, `OutAngVel` → AngVel, `OutQuat` → MeshOrientation |

### 매 프레임 흐름 (1층 그림)

1. `PaperAero`: 회전값 → N → 속도를 쪼개 따로 깎기 → 비트는 힘 → 각속도 → 회전값 조금 돌리기
2. `PaperSim`: 중력 더하기 → 위치 이동 → 바닥 검사
3. 다음 프레임이 이 값을 이어받음. **펄럭임은 줄 하나가 아니라 이 고리가 반복되며 생긴다**

### Q. "OutQuat가 같은 칸에 들어가는지 확인" 이게 무슨 말이야?

### Q. 1~-1로 비교해서 시야각 안에 있는지 보는 건 내적 아냐?

- **검색해서 나온 "오른손 법칙" 그림** → 언리얼은 왼손 좌표계(Z 위)라 그림 방향이 반대로 보임. 계산식은 같음. 기억할 한 줄: `cross(앞 X, 오른쪽 Y) = 위 Z`
