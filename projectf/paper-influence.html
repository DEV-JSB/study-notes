발에 반응하는 종이

달리는 발이 지나가면 근처 종이가 떠올라 뒤집힙니다. 새로 만든 건 "발 근처 종이의 속도를 바꾸기"뿐이고, 뒤집히는 건 3단계에서 만든 공기저항·펄럭임이 해 줍니다.

발 구 안에 있고 발이 움직이면, 종이 속도를 발 방향 × PushStrength + 위쪽 × 발 빠르기 × LiftStrength로 바꾼다. 서 있는 발은 빠르기가 0이라 아무것도 안 한다.

실험 1 · 구는 바닥에 얼마나 닿나

발목 뼈(foot_l)는 바닥에서 약 8.7cm 위(PIE에서 FootPos Z로 확인). 판정은 종이 가운데 점으로 하니, 바닥 높이에서 구가 덮는 폭 안에 가운데가 들어온 종이만 걸립니다.

바닥에서 닿는 폭
계산

피타고라스: 반폭 = √(반지름² − 높이²). 반지름 15 → 약 12cm, 20 → 약 18cm. 반지름이 발목 높이보다 작으면 바닥 종이는 영영 안 걸립니다.

이 폭은 코드에 없습니다. 코드는 length(FootPos - Pos) ≤ FootRadius, 즉 3D 거리만 봅니다. 바닥 종이는 높이가 0이라 그 3D 거리 안에 발목 높이 8.7이 섞여 있고, 풀어 쓰면 "옆으로 √(20² − 8.7²) ≈ 18cm 이내"가 됩니다. 반지름을 고를 때 쓰는 손 계산이에요. 공중에 뜬 종이는 그냥 3D 구 안이면 걸립니다.

실험 2 · 차인 종이는 어디로 가나

앞으로 = 빠르기 × Push
위로 = 빠르기 × Lift
튀는 각도
대략 높이 (v² ÷ 2g)

앞과 위는 나눠 갖는 게 아니라 각자 정합니다. 각도는 Lift ÷ Push 비율, 세기는 두 값의 크기. 높이는 중력 980, 공기저항 무시한 대략값 — 실제로는 3단계 NormalDrag가 판에 수직인 속도를 깎아서 더 낮게 뜹니다. 발 빠르기를 0으로 하면 전부 0: 서 있으면 반응 없음.

코드: 세 덩어리

// ① 닿았나?
float dist = length(FootPos - Pos);
float inside = step(dist, FootRadius);

// ② 얼마나 반응하나? (서 있으면 0)
float footSpeed = length(FootVel);
float moving = clamp(footSpeed / WakeSpeed, 0.0f, 1.0f);
float w = inside * moving;

// ③ 어디로 보내나?
float3 kick = FootVel * PushStrength + float3(0.0f, 0.0f, 1.0f) * footSpeed * LiftStrength;
OutVel = lerp(Vel, kick, w);
Touched = w;

HLSL이 낯설면: 같은 계산을 C++로

FVector PaperInfluence(const FVector& Pos, const FVector& Vel, const FVector& FootPos, const FVector& FootVel,
                       float FootRadius, float PushStrength, float LiftStrength, float WakeSpeed, float& OutTouched)
{
	if (FVector::Dist(FootPos, Pos) > FootRadius)    // ① 구 밖이면 그대로
	{
		OutTouched = 0.f;
		return Vel;
	}
	float FootSpeed = FootVel.Size();                  // ②
	float W = FMath::Clamp(FootSpeed / WakeSpeed, 0.f, 1.f);
	FVector Kick = FootVel * PushStrength + FVector::UpVector * FootSpeed * LiftStrength;   // ③
	OutTouched = W;
	return FMath::Lerp(Vel, Kick, W);
}
// Niagara가 해 주는 것: for (종이 150장) { 위 함수 }
