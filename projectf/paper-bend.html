ProjectF · 2026-11-02 · M_Paper1의 World Position Offset. 점(꼭짓점)마다 "판의 어디쯤인가(U)"를 읽어서, 가운데는 그대로 두고 긴 쪽 양 끝만 판 법선 방향으로 들어 올린다. 글 버전: paper-bend.md

① 위에서 본 종이 — 점(꼭짓점)마다 "왼쪽 끝에서 몇 % 왔나" 번호표가 붙어 있음 = U

② 옆에서 본 종이 — U로 "가운데냐 끝이냐"를 알면 끝만 들어 올릴 수 있음

휨 세기 (BendTest)1.0

위 ① 그림의 점을 클릭하면 아래 숫자가 바뀌어요. 슬라이더로 휨 세기를 바꿔 보세요.

③ M_Paper1 노드 = HLSL 다섯 줄 (노드 하나가 한 줄)

float  u     = TexCoord.x;            // TexCoord → Mask(R)  : 이 점은 긴 쪽 어디쯤? (0~1)
float  c     = (u - 0.5f) * 2.0f;     // ConstantBiasScale   : 가운데 0, 양 끝 ±1
float  shape = c * c;                 // Multiply ①          : 가운데 0, 양 끝 1
float  lift  = shape * Bend * 3.0f;   // Multiply ②③         : 몇 cm 들까 (Bend = Dynamic Parameter)
float3 wpo   = lift * VertexNormalWS; // Multiply ④          : 판에 수직 방향으로 그만큼
