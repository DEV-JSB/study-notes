종이의 공기저항은 쪼개서 따로 깎는다

PaperAero가 종이를 종이처럼 떨어뜨리는 원리. 그림, 말, 그리고 그 일을 하는 코드 줄을 나란히 놓았습니다.

화살표 더하기·빼기가 헷갈리면 벡터 더하기·빼기·곱하기 노트를 먼저 보세요.

속도를 뚫는 쪽과 비탈 쪽 두 조각으로 쪼개고, 각자 다른 브레이크로 깎은 뒤, 다시 더한다.

1. drag는 공기저항, 속력을 빼는 브레이크

속력은 더하는 것과 빼는 것의 싸움입니다.

하는 일우리 코드
중력매 순간 속력을 더함PaperSim의 Gravity
drag (공기저항)매 순간 속력을 뺌PaperAero의 NormalDrag, PlaneDrag
  • 둘이 비기면 속력이 일정해집니다. 더 빨라지지 않습니다
  • 빼는 쪽이 없으면 속력이 계속 쌓입니다. 점점 빨라집니다

2. 같은 종이라도 움직이는 방향에 따라 저항이 다르다

달리는 차 창문 밖으로 손을 내밀었을 때와 같습니다. 손바닥을 펼치면 확 밀리고, 칼날처럼 세우면 거의 안 밀립니다.

회색 = 종이가 움직이는 방향, 색 화살표 = 공기가 막는 힘. 종이는 휘지 않는 판으로 계산합니다.

브레이크맡은 방향다른 방향에는
NormalDrag면을 뚫는 쪽 (N 방향)손도 안 댐
PlaneDrag면을 따라가는 쪽 (비탈)손도 안 댐

둘은 "하나가 모자라서 다른 하나가 채워 주는" 관계가 아닙니다. 맡은 방향이 아예 다릅니다.

4. 깎는다 = 화살표 길이에 비율을 곱한다

  

    
조각남기는 비율 (예시)길이 100이었다면

    
      
뚫는 쪽30%100 → 30

      
비탈 쪽90%100 → 90

    
  

  
    
    
  • 똑같은 비율로 깎으면 다시 더해도 방향은 그대로, 길이만 줄어듭니다. Unity Rigidbody.drag가 이렇습니다
    • 
    
  • 다른 비율로 깎으면 다시 더했을 때 방향이 비탈 쪽으로 꺾입니다. 이게 미끄러짐입니다
    • 
    
  • 30%, 90%는 보이게 과장한 숫자입니다. 실제로는 한 프레임에 조금씩(NormalDrag 8이면 약 13%) 깎이고, 1초에 60번 반복됩니다

6. 회전 없이 미끄러질 때: PlaneDrag가 하는 일

  
흐린 종이 = 같은 시간 간격으로 찍은 사진. 간격이 벌어지면 빨라지는 중, 간격이 같으면 일정한 속력입니다.

  

  

    
비탈 쪽 저항 없음 (PlaneDrag 0)

    간격이 계속 벌어짐 → 계속 빨라짐
    
    
속력

  

  

    
비탈 쪽 저항 있음 (PlaneDrag 있음)

    간격이 점점 같아짐 → 어느 속력에서 더 안 빨라짐
    
    
속력

  

  
NormalDrag는 비탈 쪽을 0만큼 막습니다. 그래서 NormalDrag만 있으면 비탈 쪽 속력은 중력이 더해 주는 만큼 계속 쌓입니다. 빙판 비탈의 썰매와 같습니다. PlaneDrag는 그 비탈에 눈을 깔아 주는 것입니다.






  
7. 코드 전체와 줄별 역할

  
// PaperAero · 3-2 판 공기저항
float3 vn = dot(Vel, N) * N;          // 쪼개기: 뚫는 쪽 조각
float3 vt = Vel - vn;                 // 쪼개기: 나머지 = 비탈 쪽 조각
float keepN = max(0.0f, 1.0f - NormalDrag * DeltaTime);  // 뚫는 쪽 남길 비율
float keepT = max(0.0f, 1.0f - PlaneDrag  * DeltaTime);  // 비탈 쪽 남길 비율
OutVel = vn * keepN + vt * keepT;      // 따로 깎고 다시 더하기

  

    
줄그림에서메모

    
      
vn = dot(Vel, N) * N3번 그림 2단계의 주황dot이 "N 쪽으로 몇 cm/s인가"를 구함. 여기가 내적. 2층에서 따로 봄

      
vt = Vel - vn3번 그림 2단계의 초록전체에서 주황을 빼면 남는 것

      
keepN, keepT4번 표의 남기는 비율max(0, …)는 비율이 음수(속도 반전)가 되는 것만 막음

      
OutVel = …3번 그림 4단계의 검은 화살표꼬리에 이어 붙이는 벡터 덧셈

    
  

  
이번에는 Vel을 normalize하지 않습니다. 방향 비교가 아니라 "몇 cm/s인가"가 필요해서입니다. 덕분에 속도 0일 때 0으로 나누는 함정도 없습니다.






  
8. 조절 값 정리

  

    
값지금키우면없으면 (0)

    
      
NormalDrag8더 둥둥, 옆으로 더 많이 미끄러짐돌멩이처럼 뚝 떨어짐

      
PlaneDrag0.5덜 미끄러짐미끄러지는 속력에 한계 없음

    
  

  
왔다 갔다(흔들림)는 이 두 값이 아니라 FlipStrength 담당입니다. 회전 편에서 다룹니다.

설정본 것알게 된 것

10. 헷갈렸던 것

  

    
종이가 U자로 휘어서 가운데와 가장자리 저항이 다른 건가?아니요. 종이는 휘지 않는 판으로 계산합니다. 두 값은 종이의 부분이 아니라 움직이는 방향을 나눕니다.

    
PlaneDrag가 크면 더 많이 회전하나?아니요. PlaneDrag는 미끄러지는 속력만 깎습니다. 회전은 FlipStrength와 SpinDrag 담당입니다.

    
PlaneDrag 없이 NormalDrag만 있어도 되지 않나?3m 낙하 + 흔들림이 있는 지금 장면에서는 거의 차이가 없습니다. 4단계에서 몸이 종이를 세게 쳐서 모서리 방향으로 날릴 때를 대비한 안전장치로 0.5를 남겨 둡니다 (취향 · 바꿔도 됨).

    
NormalDrag만 있으면 왜 점점 빨라지나?NormalDrag는 비탈 쪽을 막지 않으니, 중력이 비탈 쪽으로 더하는 속력이 빠지지 않고 계속 쌓입니다.
