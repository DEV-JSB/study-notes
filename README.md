# study-notes

게임을 직접 만들며 배운 수학과 엔진 지식, 그리고 영어 원문을 직접 해석한 기록을 모은 저장소.

- 페이지로 보기: https://dev-jsb.github.io/study-notes/
- `.html` 노트는 그림을 직접 돌려 볼 수 있는 페이지 (내려받아 더블클릭해도 동작)
- `.md`는 같은 내용의 글 버전 + 개발 일지

## 폴더

| 폴더 | 내용 |
|---|---|
| `game-math/` | 프로젝트와 상관없이 다시 쓰는 수학 (내적, 벡터 더하기·빼기·곱하기) |
| `projectf/` | 파레이돌리아 모작: 종이 연출 노트, `devlog/` 하루 개발 일지 (`_TEMPLATE.md` 양식) |
| `unity/` | 유니티 · C# 연구실: Profiler로 재 본 런타임 비용(박싱, 문자열 GC), 설계 비교(상태 전파), float 정밀도(큰 좌표에서 이동이 사라지는 문제), 스레드(경쟁 상태와 lock). 실습 원본은 [unity-study](https://github.com/DEV-JSB/unity-study) |
| `english/` | 영어 원문 해석 기록 `reading/`(원문 · 내 해석 · 모범 해석 · 고칠 점)과 단어장 `vocab.html` (데이터는 `vocab.js` 하나) |
