# study-notes

게임을 직접 만들며 배운 수학과 엔진 지식을 모은 저장소.

- 페이지로 보기: https://dev-jsb.github.io/study-notes/
- `.html` 노트는 그림을 직접 돌려 볼 수 있는 페이지 (내려받아 더블클릭해도 동작)
- `.md`는 같은 내용의 글 버전 + 개발 일지
