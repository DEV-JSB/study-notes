내적(Dot Product)은 그림자 길이다

종이가 공기를 얼마나 정면으로 받는지 숫자 하나로 알아내는 도구. 화살표를 직접 돌려 보면서 1에서 -1까지 확인합니다.

B를 위에서 비췄을 때, A 위에 떨어지는 그림자 길이 = dot(A, B)

실험 1 · 화살표 두 개

0°
dot(A, B) 1.00 같은 방향 그림자가 A 쪽으로 꽉 참

각도별 값

B 각도그림자dot뜻
0°A 쪽으로 꽉 참1같은 방향
45°A 쪽으로 7할0.71대체로 같은 쪽
90°없음0직각, 서로 상관없음
135°반대쪽으로 7할-0.71대체로 반대
180°반대쪽으로 꽉 참-1정반대
  • 양수면 같은 쪽, 0이면 직각, 음수면 반대쪽
  • 45°와 315°는 둘 다 0.71. 내적은 왼쪽으로 꺾였는지 오른쪽인지 모른다. 그건 외적(Cross)이 알려준다

실험 2 · 떨어지는 종이

A 자리에 종이 법선 N(종이에 꽂은 이쑤시개), B 자리에 떨어지는 방향 V를 넣은 것.

0°
dot(N, V) -1.00 공기저항 = abs(dot) 누워서 떨어짐 → 저항 최대, 팔랑

3단계에서 쓰는 식

float drag = abs(dot(N, normalize(Vel)));   // 0 = 휙, 1 = 팔랑

종이는 앞뒤가 같아서 부호는 버리고 절댓값만 씁니다. 영상의 "팔랑 → 휙 → 다시 팔랑"은 이 값이 계속 바뀌기 때문입니다.

함정

  • 길이를 1로 안 맞추면 값이 망가집니다. 속도 500cm/s를 그대로 넣으면 dot이 -500. 반드시 normalize 후에 넣기
  • 속도가 0이면 normalize가 0으로 나누기가 됩니다. 착지한 종이가 여기에 해당하고, 3단계에서 처리합니다

확인 문제

  1. 종이가 바닥에 누워 있고(N = 위), 바람이 옆에서 수평으로 붑니다. dot은 몇이고, 바람을 많이 받을까요?
  2. dot이 -0.5면 두 화살표 사이 각도는 90°보다 클까요, 작을까요?
