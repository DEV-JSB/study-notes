화살표 더하기, 빼기, 곱하기

판 공기저항 코드는 이 세 가지와 내적만으로 되어 있습니다. 화살표 끝의 동그라미를 직접 끌어 보면서 하나씩 익힙니다.

0. 먼저 약속 두 개

벡터는 화살표입니다. 화살표에는 길이와 방향 두 가지만 있습니다. 숫자로 쓰면 (가로, 세로)처럼 칸 수를 적습니다.

  • 언리얼은 세 칸입니다. (X 앞, Y 오른쪽, Z 위)
  • 이 노트는 그림이 쉬우라고 두 칸만 씁니다. 계산하는 법은 칸 수와 상관없이 똑같습니다

화살표에는 출발점이 없다. 길이와 방향이 같으면 어디에 그려도 같은 화살표다.

이 약속 덕분에 화살표를 들어서 다른 화살표 끝에 옮겨 붙일 수 있습니다. 아래 더하기와 빼기가 전부 이 약속 위에 서 있습니다.

1. 한눈에 보기

표에서 볼 것은 나오는 것 칸입니다. 내적만 숫자가 나오고 나머지는 전부 화살표가 나옵니다. 그래서 dot(Vel, N) * N은 "내적으로 숫자를 얻고, 그 숫자를 화살표에 곱해서 다시 화살표로 만든다"는 뜻입니다. 4번과 5번에서 자세히 봅니다.

2. 더하기 = 이어 붙이기

A를 먼저 가고, A가 끝난 자리에서 B를 이어서 가면 어디에 도착하는가. 그 도착점까지 가는 화살표가 A + B입니다.

동그라미를 끌거나, 누른 뒤 방향키로 한 칸씩 옮깁니다. 파랑은 A의 끝, 검정은 도착점입니다.
  • 계산은 칸끼리 더하면 끝입니다. 가로는 가로끼리, 세로는 세로끼리 더합니다
  • 흐린 점선 B는 옮기기 전 자리입니다. 길이와 방향이 같으니 같은 화살표입니다
  • 순서를 바꿔 B를 먼저 가도 같은 곳에 도착합니다. 버튼으로 확인해 보세요

게임에서: PaperSim의 중력이 매 프레임 하는 일이 더하기입니다. 지금 속도 화살표 끝에 "중력이 이번 프레임에 주는 작은 아래 화살표"를 이어 붙입니다. 그게 다음 프레임의 속도입니다.

Velocity = Velocity + Gravity * DeltaTime;   // 지금 속도 끝에 작은 아래 화살표를 이어 붙임

3. 빼기 = 떼어내기

전체 화살표 Vel에서 한 조각 vn을 떼어내면 무엇이 남는가. 남은 것이 vt입니다.

회색 동그라미는 Vel의 끝, 주황 동그라미는 vn의 끝입니다.
  • 그림으로는 "빼는 것의 끝에서 전체의 끝으로 가는 화살표"입니다. vn 끝에서 Vel 끝으로 가는 초록이 vt입니다
  • 계산은 칸끼리 빼면 끝입니다
  • 빼기는 더하기를 거꾸로 한 것입니다. vn 끝에 vt를 이어 붙이면 다시 Vel 끝에 도착합니다
float3 vt = Vel - vn;   // Vel에서 뚫는 쪽 조각을 떼어내면, 비탈 쪽 조각이 남는다

4. 곱하기 = 길이만 바꾸기

화살표에 숫자 하나를 곱하면 방향은 그대로, 길이만 그 배수가 됩니다. 계산은 칸마다 같은 숫자를 곱합니다.

곱하는 숫자화살표는
1보다 큼같은 방향으로 길어짐
0과 1 사이 (0.3, 0.9)같은 방향으로 짧아짐. 종이 코드가 쓰는 게 이것
0길이 0. 화살표가 사라짐
음수방향이 뒤집힘

마지막 줄이 중요합니다. 종이 코드에서 keepN = max(0, 1 - NormalDrag * dt)처럼 max(0, …)로 감싼 이유가 이것입니다. keep이 음수가 되면 속도 조각이 뒤집혀 종이가 거꾸로 튕겨 나갑니다. 0 아래로 못 내려가게 막아 둔 것입니다.

vn * keepN   // 뚫는 쪽 조각을 keepN배로 줄임 (방향은 그대로)
vt * keepT   // 비탈 쪽 조각을 keepT배로 줄임

5. 길이 1짜리 화살표 × 숫자 = 줄자

곱하기의 특별한 경우입니다. N처럼 길이가 딱 1인 화살표에 숫자를 곱하면, N 방향으로 놓인 줄자에서 그 눈금까지 가는 화살표가 됩니다.

버튼을 켜면 숫자를 손으로 고르지 않고 dot(Vel, N), 즉 Vel의 그림자 길이로 정합니다. 그러면 나오는 화살표가 바로 vn이고, 남은 초록이 vt입니다. 회색 동그라미를 끌어 Vel을 바꿔 보세요.

float3 vn = dot(Vel, N) * N;
//          ─────┬─────   ┬
//               │        └ 길이 1인 N 방향 줄자
//               └ 그림자 길이(숫자). 줄자에서 몇 눈금인지
  • N의 길이가 1이 아니면 눈금 간격이 틀어져서 이 줄이 맞지 않습니다. 그래서 N은 늘 길이 1로 만들어 씁니다
  • 종이 예시에서는 dot이 -130이었습니다. 줄자에서 -130 눈금, 즉 N 반대쪽으로 130만큼 가는 화살표가 vn입니다

6. 이제 PaperAero를 다시 읽기

종이 예시 숫자 그대로입니다. Vel은 아래로 150, 종이는 30° 기울었고, keepN 0.3, keepT 0.9입니다.

float3 vn = dot(Vel, N) * N;            // 내적으로 숫자 → 곱하기로 N 방향 화살표
float3 vt = Vel - vn;                   // 빼기: 남은 조각
OutVel    = vn * keepN + vt * keepT;    // 곱하기로 따로 줄이고, 더하기로 이어 붙임

세 줄 모두 이 노트의 연산만 씁니다. 방향이 꺾이는 이유도 여기서 보입니다. 두 조각을 같은 비율로 줄였다면 ③의 화살표는 원래 Vel과 같은 방향에 짧아지기만 합니다. 다른 비율로 줄였기 때문에 이어 붙인 결과의 방향이 바뀝니다.

판 공기저항 노트의 3번(한 프레임에 일어나는 일)을 이 노트를 본 뒤 다시 넘겨 보세요.

8. 자주 헷갈리는 것

화살표를 다른 자리로 옮겨 그려도 되나요?네. 길이와 방향만 같으면 같은 화살표입니다. 더하기에서 B를 A 끝으로 옮기는 것, 판 공기저항 6단계에서 vt를 출발점으로 옮기는 것 모두 이 약속 덕분입니다.
더하기 순서를 바꾸면요?같은 곳에 도착합니다. A 다음 B로 가든, B 다음 A로 가든 결과가 같습니다.
빼기 순서를 바꾸면요?정반대 화살표가 나옵니다. Vel - vn은 vt이고, vn - Vel은 vt를 뒤집은 것입니다.
0.3을 곱하면 방향도 바뀌나요?아니요. 길이만 30%가 됩니다. 방향은 음수를 곱할 때만 바뀌고, 그때는 정반대로 뒤집힙니다.
화살표에 화살표를 곱할 수도 있나요?이 노트의 곱하기는 화살표와 숫자 사이의 것입니다. 화살표끼리는 내적(숫자가 나옴)이나 외적(나중에 배울 것)을 씁니다.
