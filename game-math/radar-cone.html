레이더 원뿔 판정: 그림자가 기준보다 길면 안이다

제자리에서 도는 터렛이 "타겟이 내 앞 원뿔 안에 있나"를 내적 하나로 판단하는 방법. 위에서 내려다본 레이더를 직접 돌리고 타겟을 끌어 보면서 CheckFireTarget이 하는 일을 숫자로 확인합니다.

타겟 방향과 터렛 정면을 둘 다 길이 1로 맞춰 내적한 값(그림자 길이)이 cos(반폭)보다 크거나 같으면 원뿔 안.

45°의 함정

45°에서는 라디안(0.785)과 cos(0.707)가 우연히 비슷해서, cos를 빼먹어도 대충 맞아 보입니다. 반폭을 60°로 올려 보세요. 라디안 1.047, cos 0.5. 검증할 땐 값을 두세 개 넣어 봐야 해요.

손 계산 검증 (desk check)

각도가 작을수록(정면일수록) cos는 커집니다. 그래서 "안"은 기준보다 크거나 같다예요. 부등호가 헷갈리면 정면(1)을 넣어 true가 나오는지만 보면 됩니다.

왜 왼쪽 50°와 오른쪽 50°가 같은 판정인가

  • cos(-50°) = cos(50°). 내적은 얼마나 벌어졌나만 알고 어느 쪽으로 벌어졌는지는 모릅니다.
  • 높이(Z)를 지우지 않았으니 위·아래·대각선 50°도 같은 값. 실제 3D 판정 범위는 정면 축을 둘러싼 동그란 원뿔이에요. 이 페이지의 그림은 그 원뿔을 위에서 자른 단면입니다.
  • 왼쪽인지 오른쪽인지 알려면 외적이 필요합니다. 과정 1의 연습 2(맞은 방향 표시)와 미사일이 어느 쪽으로 꺾을지 정할 때 다시 나와요.

경계선 그리기: 정면을 돌린다

const FVector PlusEdge  = Forward.RotateAngleAxis( DetectDeg, FVector::UpVector);
const FVector MinusEdge = Forward.RotateAngleAxis(-DetectDeg, FVector::UpVector);
DrawDebugLine(GetWorld(), Start, Start + PlusEdge * DetectRadius, FColor::Red, false, -1.f, 0, 2.f);
경계회전경첩(축)
좌우Yaw (도리도리)위 Z — 이 터렛은 Yaw로만 돌아서 FVector::UpVector로 충분
위아래Pitch (끄덕끄덕)터렛의 오른쪽 — GetActorRightVector(). FVector::RightVector는 월드 상수라 터렛과 같이 안 돎
  • RotateAngleAxis는 도(°)를 받고 새 벡터를 돌려줍니다. 길이와 원본은 그대로예요. FQuat(Axis, Angle)은 라디안이니 섞지 않기.
  • 위 실험 그림에서는 빨강(+)이 화면 아래(+Y) 쪽으로 돕니다. 실제 에디터에서 빨강이 터렛의 왼쪽인지 오른쪽인지는 직접 보고 확인한 뒤 LeftEdge/RightEdge로 이름을 바꾸세요. 언리얼은 왼손 좌표계라 교과서 그림과 반대로 보일 수 있어요.
