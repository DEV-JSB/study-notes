# 벡터 더하기·빼기·곱하기 학습 노트

> 2026-10-23 · ProjectF 3단계 회고 준비 · 판 공기저항 코드를 읽기 위한 기초

**🎛 직접 끌어 보는 그림:** https://dev-jsb.github.io/study-notes/game-math/vector-ops.html
(같은 폴더의 `vector-ops.html`)

## 약속 두 개

- 벡터 = 화살표. **길이**와 **방향**만 있다. 숫자로는 (가로, 세로) 칸 수
- **화살표에는 출발점이 없다.** 길이와 방향이 같으면 어디에 그려도 같은 화살표 → 다른 화살표 끝으로 옮겨 붙일 수 있다

## 한눈에 보기

| 연산 | 넣는 것 | 나오는 것 | 그림으로 하면 | 종이 코드 |
|---|---|---|---|---|
| 더하기 | 화살표, 화살표 | 화살표 | 앞 화살표 끝에 이어 붙이기 | `vn*keepN + vt*keepT` |
| 빼기 | 화살표, 화살표 | 화살표 | 전체에서 한 조각 떼어내기 | `Vel - vn` |
| 곱하기 | 화살표, 숫자 | 화살표 | 길이만 늘이고 줄이기 | `vn * keepN` |
| 내적 | 화살표, 화살표 | **숫자** | 그림자 길이 | `dot(Vel, N)` |

내적만 숫자가 나온다. 그래서 `dot(Vel, N) * N` = 내적으로 숫자를 얻고, 화살표에 곱해서 다시 화살표로 만든다.

## 더하기 = 이어 붙이기

- A를 가고, A 끝에서 B를 이어 가면 도착하는 곳까지의 화살표가 A + B
- 계산: 가로끼리, 세로끼리 더한다. (4, 1) + (1, 3) = (5, 4)
- 순서를 바꿔도 같은 곳에 도착한다
- 게임에서: `Velocity = Velocity + Gravity * DeltaTime` → 지금 속도 끝에 작은 아래 화살표를 이어 붙임

## 빼기 = 떼어내기

- 그림: **빼는 것의 끝에서 전체의 끝으로 가는 화살표**
- 계산: 칸끼리 뺀다. (6, 4) − (1, 3) = (5, 1)
- 빼기는 더하기를 거꾸로 한 것. vn 끝에 vt를 이어 붙이면 다시 Vel 끝
- 순서를 바꾸면 정반대 화살표

## 곱하기 = 길이만 바꾸기

| 곱하는 숫자 | 화살표는 |
|---|---|
| 1보다 큼 | 같은 방향으로 길어짐 |
| 0과 1 사이 (0.3, 0.9) | 같은 방향으로 짧아짐 ← 종이 코드 |
| 0 | 사라짐 |
| 음수 | 방향이 뒤집힘 |

- `keepN = max(0, 1 - NormalDrag * dt)`의 `max(0, …)`는 keep이 음수가 되어 속도가 뒤집히는 것(종이가 거꾸로 튕김)을 막는 것

## 길이 1짜리 화살표 × 숫자 = 줄자

- 길이가 딱 1인 N에 숫자 d를 곱하면 **N 방향 줄자에서 d 눈금까지 가는 화살표**
- `vn = dot(Vel, N) * N` → 그림자 길이(숫자)만큼 N 줄자를 따라간 화살표
- N 길이가 1이 아니면 눈금이 틀어진다. 그래서 N은 늘 길이 1

## PaperAero 다시 읽기

```hlsl
float3 vn = dot(Vel, N) * N;            // 내적으로 숫자 → 곱하기로 N 방향 화살표
float3 vt = Vel - vn;                   // 빼기: 남은 조각
OutVel    = vn * keepN + vt * keepT;    // 곱하기로 따로 줄이고, 더하기로 이어 붙임
```

1. 쪼개기 (곱하기·빼기)
2. 따로 줄이기 (곱하기): vn × 0.3, vt × 0.9
3. 이어 붙이기 (더하기)

같은 비율로 줄였다면 방향은 그대로, 짧아지기만 한다. **다른 비율로 줄였기 때문에 방향이 꺾인다.**

## 언리얼과 유니티에서는

| | Niagara HLSL | UE C++ | Unity C# |
|---|---|---|---|
| 화살표 | `float3` | `FVector` | `Vector3` |
| 더하기 | `a + b` | `A + B` | `a + b` |
| 빼기 | `a - b` | `A - B` | `a - b` |
| 곱하기 | `a * 0.3f` | `A * 0.3f` | `a * 0.3f` |
| 내적 | `dot(a, b)` | `FVector::DotProduct(A, B)` | `Vector3.Dot(a, b)` |
| 길이 | `length(a)` | `A.Size()` | `a.magnitude` |
