어림수와 나머지: 수직선의 왼쪽·오른쪽, 그리고 시계

내림(floor), 올림(ceil), 반올림(round)은 수직선 위에서 어느 정수로 가는지의 문제이고, 나머지(%)는 시계를 몇 칸 돌았는지의 문제입니다. 두 이야기는 사실 하나로 이어져 있고, 음수에서 함정이 생깁니다. 언리얼 C++과 Unity C# 함수를 나란히 정리했어요.

1. 기호: ㄴ자와 ㄱ자

⌊x⌋내림 · floor (바닥)가로선이 아래에 있는 ㄴ 모양. x보다 작거나 같은 정수 중 가장 큰 것 → 수직선 왼쪽으로
⌈x⌉올림 · ceiling (천장)가로선이 위에 있는 ㄱ 모양. x보다 크거나 같은 정수 중 가장 작은 것 → 수직선 오른쪽으로

"왼쪽/오른쪽"은 0 쪽이 아니라 수직선 방향입니다. 그래서 ⌊-2.5⌋ = -3.

  • (int) 캐스팅은 floor가 아닙니다. 소수점을 떼어내 0 쪽으로 갑니다. 양수에서만 floor와 같아요. (C++·C# 언어 표준)
  • -2.5는 UE와 Unity가 우연히 같습니다. UE는 큰 쪽(-2), Unity는 짝수 쪽(-2)이라서요. -3.5를 넣어 보면 UE는 -3, Unity는 -4로 갈라집니다.
반올림은 언어마다 다르다: .5를 어디로 보내나
  • UE FMath::RoundToInt: FloorToInt(F + 0.5f)라서 .5는 언제나 큰 쪽(오른쪽)으로 갑니다. (Epic 공식: 엔진 소스 GenericPlatformMath.h 309줄에서 직접 확인)
  • Unity Mathf.Round, Mathf.RoundToInt, C# Math.Round: .5는 짝수 쪽으로 갑니다. 2.5 → 2, 3.5 → 4 (은행가 반올림, banker's rounding). (Unity·.NET 공식 문서)
  • C++ std::round: 0에서 먼 쪽으로 갑니다. -2.5 → -3. (C++ 표준)

TBH(Unity)에서 쓰던 감각 그대로 언리얼 코드를 짜면 0.5, 2.5 같은 경계값에서 1씩 어긋납니다.

실험 2 · 나머지는 시계 돌리기

칸이 N개인 시계에서 0부터 a칸 이동합니다(음수면 거꾸로). 점선은 버려지는 바퀴(몫)이고, 주황색이 마지막 남은 칸(나머지)입니다.

a를 음수로 내려 보세요. 시계는 거꾸로 돌아 양수 칸에 도착하는데, % 연산자는 음수를 돌려줍니다.

3. 두 이야기는 하나다: 나머지 = 바퀴 수를 floor로 셀 때

나눗셈을 a = 몫 × N + 나머지로 쪼갤 때, 몫을 어떻게 정수로 만드느냐에 따라 나머지가 달라집니다.

시계 나머지 (수학)   = a − N × ⌊a / N⌋        몫을 floor (왼쪽)로
% 연산자 (C++·C#)   = a − N × (int)(a / N)    몫을 버림 (0 쪽)으로

예: a = -1, N = 4
  floor:  ⌊-0.25⌋ = -1  →  -1 − 4 × (-1) =  3   ← 시계
  버림:   (int)(-0.25) = 0  →  -1 − 4 × 0  = -1   ← % 연산자

그래서 2절의 "(int)는 floor가 아니다"와 시계의 "음수 나머지 함정"은 같은 원인입니다. 양수에서는 floor와 버림이 같아서 둘 다 문제가 안 보이고, 음수에서만 갈라집니다. Unity Mathf.Repeat가 바로 floor 쪽 식으로 만들어져 있어요.

함정: FMath::Wrap은 인덱스용이 아니다

이름만 보면 시계 함수 같지만, Wrap(X, Min, Max)는 Min과 Max를 둘 다 포함하고 같은 점으로 봅니다(각도에서 -180°와 180°처럼). 엔진 소스를 따라가 보면 Wrap(4, 0, 4)는 4를 그대로 돌려줍니다. 칸이 4개인 배열이라면 범위를 벗어난 값이에요. 배열 인덱스에는 ((A % N) + N) % N을 쓰세요. (Epic 공식: UnrealMathUtility.h 608줄 구현에서 확인)

6. 수학에서의 위치

  • 반올림·올림·버림(어림하기): 초등 4~5학년. 한국 교과에선 초5 "수의 범위와 어림하기"
  • 나머지가 있는 나눗셈: 초등 3학년
  • ⌊x⌋ 기호: 한국 고등 수학 문제에서는 가우스 기호 [x]로 나옵니다. 정식 교과 단원인지는 확실치 않아요
  • 시계 산수(모듈러 산술, modular arithmetic): 학교 교과 밖. 대학 이산수학·정수론. 강의의 시계 그림이 이 분야의 표준 그림입니다
