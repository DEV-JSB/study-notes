외적(Cross Product)은 회전축이다

내적은 "얼마나 같은 쪽인가"만 알려줬습니다. 외적은 "어느 쪽으로 돌았나"를 알려줍니다. 종이가 뒤집힐 때 도는 축이 여기서 나옵니다.

cross(A, B) = A와 B 둘 다에 직각으로 꽂힌 화살표 방향 = A를 B 쪽으로 돌리는 회전축 · 길이 = 둘이 얼마나 직각에 가까운가 (0 ~ 1)

실험 1 · 바닥 위의 화살표 두 개

A와 B는 바닥에 눕혀 놓은 화살표. 보라색이 외적인데, 바닥에서 위나 아래로 솟습니다.

45°
cross(A, B) 의 위아래 값 +0.71 위로 솟음 위에서 내려다보면 A→B가 시계방향 비교: dot(A, B) = 0.71

내적이 못 하던 것

B 각도dotcross뜻
0°10한 줄로 겹침 → 돌 축이 없음
45°0.71+0.71위로 솟음
90°0+1직각 → 외적 길이 최대
180°-10정반대도 한 줄 → 축 없음
270°0-1아래로 최대
315°0.71-0.71아래로 솟음
  • 45°와 315°는 dot이 같습니다(0.71). 내적만으로는 구별이 안 됩니다
  • cross는 +0.71과 -0.71로 갈립니다. 부호가 "어느 쪽으로 돌았나"입니다
  • 길이는 직각일 때 1, 한 줄일 때 0입니다. 내적과 반대로 움직입니다

언리얼에서 방향 외우기

cross(앞 X, 오른쪽 Y) = 위 Z
cross(오른쪽 Y, 앞 X) = 아래 -Z     // 순서를 바꾸면 반대
  • 외적 화살표 끝에서 내려다보면, A가 B 쪽으로 시계방향으로 돕니다
  • 언리얼은 왼손 좌표계(Z 위)라서 시계방향입니다. Unity도 왼손이라 Vector3.Cross(forward, right) = up으로 똑같습니다
  • 수학책이나 블렌더에서 말하는 "오른손 법칙(반시계)"은 오른손 좌표계 기준입니다. 검색해서 나온 그림과 방향이 반대로 보여도 계산식은 같습니다

실험 2 · 기울어진 채 떨어지는 종이 (옆에서 본 모습)

왼쪽으로 기울든 오른쪽으로 기울든 공기저항(abs dot)은 같습니다. 하지만 돌아야 할 방향은 반대이고, 그걸 외적이 알려줍니다.

30°
공기저항 abs(dot(N, V)) 0.87 cross(N, V) = 회전축 +0.50 화면 밖(나를 향함) ⊙ N이 V 쪽으로, 화면에서 시계방향으로 돌아감

3단계에서 쓰는 두 줄

float  drag = abs(dot(N, dir));    // 얼마나 세게 (내적)
float3 axis = cross(N, dir);       // 어느 쪽으로 돌까 (외적)

내적이 세기를, 외적이 방향을 맡습니다. 실제로 얼마나 빨리 돌릴지, 쿼터니언에 어떻게 쌓을지는 3단계에서 직접 짭니다.

함정

  • 순서가 중요합니다. cross(N, V)와 cross(V, N)은 정반대 축입니다. 내적은 순서를 바꿔도 같아서 이 습관이 생기기 쉽습니다
  • 한 줄이면 길이가 0입니다. 누운 종이가 똑바로 떨어지면 N과 V가 한 줄이라 축이 사라집니다. 이걸 그대로 normalize하면 0으로 나누기입니다
  • 회전축으로 쓸 때는 길이 1로 맞춰야 합니다. 길이(직각 정도)는 따로 꺼내서 "얼마나 세게"에 씁니다

확인 문제

  1. cross(A, B)가 위를 가리킵니다. cross(B, A)는 어디를 가리킬까요?
  2. 종이가 납작하게 누운 채 똑바로 떨어집니다(N = 위, V = 아래). cross(N, V)의 길이는 얼마이고, 종이는 돌까요?
